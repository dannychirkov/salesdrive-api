По API можна оновлювати дані заявки:

  • статус заявки;
  • менеджер заявки;
  • ТТН;
  • усі поля заявки і контакту, дозволені до редагування

По API не можна оновлювати:

  • товарні позиції в заявці;
  • дані контактів, прив'язаних до заявки;
  • місто, відділення, адреса Нової Пошти/Укрпошти.

Ви можете оновлювати заявки в SalesDrive:

  • за номером заявки (id);
  • за зовнішнім номером заявки (externalId).

При оновленні заявки по API, ви можете передавати не всі поля заявки, а лише ті поля, які оновлюєте.
